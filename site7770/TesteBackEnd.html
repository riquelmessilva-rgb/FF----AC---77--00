A) Documentos de Testes

1. Plano de Teste

Define o que, como, quando e quem vai testar: escopo, riscos, cronograma e ferramentas.

2. Casos de Teste

Passo a passo de cada teste, com dados de entrada e o resultado esperado.

3. Relatório de Incidentes

Registra cada defeito encontrado: descrição, gravidade, evidências e status.

4. Relatório de Resumo

Mostra o resultado final: quantos testes passaram, falharam e se o sistema pode ser liberado.

B) Elaboração do Caso de Teste

Conceito

Caso de teste é um conjunto de condições, dados de entrada e resultados esperados criado para verificar se uma funcionalidade do sistema está correta.

Exemplo: Login de usuário (API Back End)
