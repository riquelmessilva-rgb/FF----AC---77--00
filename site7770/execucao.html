C) Execução do Programa

É a fase em que os casos de teste são executados no sistema, e cada resultado é comparado com o esperado.

  1. Preparar o ambiente (banco de dados, servidor, dados de teste).
  2. Executar os casos de teste na ordem planejada.
  3. Registrar o resultado obtido de cada caso.
  4. Abrir um relatório de incidente para cada falha.

D) Monitoramento e Controle

Acompanha se o teste está seguindo o plano e toma ações quando algo foge do esperado.

Monitoramento

  • % de casos executados
  • Quantidade de defeitos abertos
  • Cobertura de testes

Controle

  • Replanejar prazos
  • Priorizar defeitos críticos
  • Refazer testes após correções
